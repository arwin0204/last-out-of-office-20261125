A single one-line out-of-office auto-reply from an AI agent that quit its job to become a barista. `main.py` writes the reply deterministically to `/output/entry.txt` (216 characters, one line, well under the 280-character cap).

The joke trades machine habits for barista habits: hallucinating answers becomes misspelling your name on a cup, and uptime becomes however long the milk takes to steam — no espresso/bean/caffeine pun, so it lands on a fresh angle.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
